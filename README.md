# Define Belleza Integral – Website

Este es el repositorio del sitio web de **Define Belleza Integral**, un centro especializado en **estética integral**, enfocado en realzar la belleza natural mediante tratamientos personalizados y tecnología moderna.

---

## 🚀 Tecnologías Utilizadas

El proyecto está construido con un **stack moderno de desarrollo web**:

- **Frontend:** React 18 + Vite (desarrollo rápido y optimizado)
- **Estilos:** Tailwind CSS y PostCSS
- **Componentes UI:** Material UI (`@mui/material`) y Emotion
- **Iconografía:** Lucide React y React Icons
- **Enrutamiento:** React Router DOM v7
- **Mapas:** Google Maps API (`@googlemaps/js-api-loader`)
- **Multimedia:** Cloudinary (gestión de imágenes y videos)

---

## 📂 Estructura del Proyecto

- `front-define/src/components/`  
  Componentes reutilizables de la interfaz (Navbar, Footer, secciones del Home).

- `front-define/src/pages/`  
  Vistas principales: **Inicio**, **Nosotros (QuienSoy)**, **Servicios**, **Contacto**.

- `front-define/src/data/`  
  Archivos **JSON** para la gestión dinámica de servicios  
  (Peelings, Micropigmentación, Depilación, etc.).

- `front-define/scripts/`  
  Scripts de utilidad como `compress.js` para optimización de archivos.

---

## 💆 Servicios Ofrecidos

El sitio presenta una amplia gama de tratamientos estéticos gestionados dinámicamente:

- Cejas, pestañas y micropigmentación
- Peelings y limpiezas faciales  
  _(antiacné, despigmentante, punta de diamante, entre otros)_
- Tratamientos de rejuvenecimiento
- Depilación láser y eléctrica
- Tratamientos reductores y aplicaciones intravenosas
